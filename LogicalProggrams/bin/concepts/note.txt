Rehashing:

Rehashing is the process of increasing the size of a hashmap and redistributing the elements to new buckets based on their new hash values. 
It is done to improve the performance of the hashmap and to prevent collisions caused by a high load factor.

can stringbuilder be hashmap key ?
StringBuilder/Buffer is also mutable which is generally not a good idea to use as a key for a HashMap since storing the value under
 it can cause the value to be inaccessible after modification. 
StringBuilder uses Object 's default hashcode() implementation, whereas Strings are compared by value for the map keys

4.What if HashMap hashcode() returns same value
A hashcode() that always returns the same value is valid but not very effective. 
In this case the comparison will always return true, so the equals() method will always be executed. There is no performance improvement in this case.

11. Can we execute @Putmapping logic inside @PostMapping
--YES,  but it will violate the principle of Restful design
Not recommended
@PostMapping -> not-idepotent -- resource is not modified-- when we hit multiple requests it will save in DB multiple times
@Putmapping -> idepotent -- resource is  modified - in DB no new resource added
if we execute update logic in @Postmapping it will create new resource in DB every time
